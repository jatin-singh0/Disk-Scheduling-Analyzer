About DiskPilot

DiskPilot is an operating-systems disk scheduling analyzer. All scheduling math runs in C (backend/algorithms.c). The Python server loads it as a shared library, or the browser loads the optional WebAssembly build. This page only renders what the C engine returns.

Conventions: SCAN and C-SCAN travel to the disk edge; LOOK and C-LOOK stop at the last request. C-SCAN and C-LOOK return jumps are counted in total movement. Duplicate requests are kept (0-cost seeks).

Algorithms: FCFS (arrival order), SSTF (nearest request first), SCAN (elevator), C-SCAN (circular elevator), LOOK, C-LOOK.
